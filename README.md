# 📰 Fake News Detection using Machine Learning

## 📌 Introduction

Fake news has become a major problem in the digital world, especially with the rapid growth of social media and online news platforms. The spread of misleading or false information can influence public opinion and create confusion.

This project aims to build a machine learning model that can automatically classify news articles as **real or fake** based on their content.

---

## 🎯 Objective

The main objective of this project is to:

* Detect whether a news article is fake or real
* Apply natural language processing (NLP) techniques
* Build and evaluate a classification model

---

## 📊 Dataset

* The dataset contains news articles labeled as **real** or **fake**
* It includes features such as:

  * Title
  * Text content
  * Label (Fake/Real)

---

## ⚙️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Natural Language Processing (NLP)

---

## 🧠 Methodology

1. Data Cleaning and Preprocessing
2. Text Vectorization (TF-IDF)
3. Model Training (e.g., Logistic Regression / Naive Bayes)
4. Model Evaluation

---

## 📈 Results

* Achieved accuracy: **(91%)**
* The model performs well in identifying fake news articles

---

## 🚀 How to Run

1. Clone the repository
2. Install required libraries
3. Run the Jupyter Notebook

---

## 💡 Conclusion

This project demonstrates how machine learning can be used to tackle real-world problems like fake news detection. With further improvements, this model can be integrated into web platforms to filter misleading information.
